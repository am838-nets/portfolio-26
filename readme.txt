  鄭乃慈 PORTFOLIO 網站  ·  自助編輯說明
═══════════════════════════════════════════════════════════════

這個網站不需要寫程式就能改。看完這份說明,你就能自己加照片、
換照片、改順序、刪照片。所有檔案都在你電腦上,改完重新上傳
到 Netlify 就會更新。


─── 資料夾結構 ─────────────────────────────────────────────────

  site/
  ├── index.html         ← 首頁(3D 互動)
  ├── photography.html   ← 攝影頁(底片堆疊)
  ├── photos/            ← 全部底片照片放這裡
  │   ├── 01.jpg
  │   ├── 02.jpg
  │   ├── ...
  │   └── 60.jpg
  └── README.txt         ← 你正在看這個


─── 1. 加新照片 ───────────────────────────────────────────────

步驟 1:準備照片
  - 把照片裁成 3:2 比例(例如 1920×1280)
  - 存成 JPG 檔
  - 命名成下一個編號:現在最大是 60,所以新照片叫 61.jpg
  - 第二張新照片叫 62.jpg,依此類推

步驟 2:把照片放進資料夾
  - 直接把 61.jpg、62.jpg 拖進 site/photos/ 資料夾

步驟 3:編輯 photography.html
  - 用記事本、VSCode、Sublime Text 等任何文字編輯器打開
  - 用 Ctrl+F (Mac: Cmd+F) 搜尋  const photos = [
  - 你會看到一長串像這樣的列表:

      const photos = [
        './photos/51.jpg',
        './photos/56.jpg',
        './photos/52.jpg',
        ... 中間 60 行 ...
        './photos/02.jpg',
      ];

  - 在 ];  之前加上新的一行:

      const photos = [
        './photos/51.jpg',
        ... 略 ...
        './photos/02.jpg',
        './photos/61.jpg',    ← 新增
        './photos/62.jpg',    ← 新增
      ];

  - 注意:每一行前面要有兩個空格,後面用單引號 '...' 包起來,
         結尾要加逗號 ,

步驟 4:更新計數器
  - 在同一個檔案裡用 Ctrl+F 搜尋  / 60
  - 把它改成  / 62  (新的總數)
  - 整份檔案應該只會有 1 個地方需要改

步驟 5:存檔,測試,上傳
  - 存檔
  - 雙擊 photography.html 在瀏覽器開來檢查
  - 沒問題就把整個 site 資料夾的內容拖到 Netlify dashboard


─── 2. 刪掉某張照片 ─────────────────────────────────────────

步驟 1:打開 photography.html
步驟 2:用 Ctrl+F 搜尋那張照片的編號,例如:  ./photos/15.jpg
步驟 3:把整行刪掉(包含結尾的逗號)
步驟 4:更新計數器  / 60  改成  / 59
步驟 5:存檔,上傳

(註:photos 資料夾裡的 15.jpg 檔案可以留著沒關係,網站不會
 顯示它就行。但想清乾淨的話也可以順手刪掉。)


─── 3. 換照片內容(同一格換成新圖) ────────────────────────

最簡單:
  - 把你想用的新照片命名成跟舊的一樣,例如 15.jpg
  - 直接覆蓋 site/photos/ 裡的舊 15.jpg
  - HTML 完全不用改
  - 上傳網站

注意:Netlify 有快取,可能要強制重新整理(Ctrl+Shift+R)
     才會看到新照片。


─── 4. 改照片出現順序 ────────────────────────────────────

打開 photography.html,在 const photos = [ ... ]; 這段裡
直接剪剪貼貼調整順序就好。

注意:程式會把照片**輕微洗牌**,所以順序不會 100% 跟你寫的一樣。
洗牌規則:
  - 前 9 張會在前 9 名內互相打亂(確保開場永遠是強照片)
  - 中間 23 張會在中段打亂
  - 後面 28 張會在後段打亂

所以如果你想要某張照片絕對開場,把它放在前 9 名的範圍內就行,
不能保證它是第 1 張,但保證會在前 9 張內出現。

想完全關掉洗牌? 把這三行刪掉:
  shuffleSection(photos, 0, 9);
  shuffleSection(photos, 9, 32);
  shuffleSection(photos, 32, 60);


─── 5. 改首頁的東西 ────────────────────────────────────

打開 index.html
用 Ctrl+F 搜尋你想改的文字,例如:
  - "NAI TZU CHENG" → 改名字
  - "PHOTOGRAPHY"   → 改類別名
  - "DESIGN"        → 改類別名
  - "CREATION"      → 改類別名


─── 6. 處理照片技巧(壓縮成 3:2) ─────────────────────

如果你的新照片不是 3:2 比例,放進來可能會變形或有黑邊。

最快的做法:
  - Mac:用「預覽程式」開啟照片 → 工具 → 調整大小 / 裁切
  - Windows:用「相片」app → 編輯 → 裁切 → 選 3:2
  - 或上 photopea.com(免費的線上 Photoshop)
  - 寬度建議:1920px(高度自動變成 1280px)
  - 存檔時 JPG 品質選 80-90 之間

如果原始照片畫質很高、檔案很大(超過 2MB),
建議先壓縮過再放進來,不然網站會變慢。


─── 7. 上傳到 Netlify(每次改完都要做) ─────────────

1. 打開瀏覽器去  https://app.netlify.com
2. 找到你的網站 nets-portfolio
3. 點 Deploys 分頁
4. 把整個 site 資料夾的「內容」(不是資料夾本身,
   是裡面的 index.html、photography.html、photos/ 等)
   拖進 dashboard 中央那個虛線框
5. 等 30 秒,看到綠色 Published 就完成了
6. 去  https://nets-portfolio.netlify.app  按 Ctrl+Shift+R
   強制重新整理,確認改動有上去


─── 8. 救命!我把檔案改壞了 ────────────────────────

不要慌,你還有原始的 portfolio_site_v8.zip
重新解壓縮一份,剛剛改的內容只要重做一次就好。

建議:每次大改之前,先複製整個 site 資料夾備份一份,
取名 site_20260427_備份 之類的。


─── 常見問題 ──────────────────────────────────────

Q: 加完照片網站怎麼沒變?
A: 八成是 Netlify 的瀏覽器快取。按 Ctrl+Shift+R 強制重新整理。
   還是不行的話,確認 Netlify 真的有重新部署(Deploys 頁面)。

Q: 照片顯示成裂掉的圖示?
A: 檢查檔案路徑跟檔名大小寫。 ./photos/15.JPG 跟
   ./photos/15.jpg 在 Netlify 上是不一樣的!統一用小寫 .jpg

Q: 全部照片都看不到?
A: 看你打開的檔案是不是 photography.html (不是 index.html)。
   也檢查 const photos 那段是不是格式跑掉(每行結尾要有逗號)。

Q: 我想完全換掉一個分類的概念
A: 找 Claude 重做就好,不用自己硬改。
